# ADR-0005: Licensing — MIT code, CC BY-SA 4.0 original assets
- Status: Accepted
- Date: 2026-09-26

## Context
Open-source game: we want wide reuse of code and a commons of Indonesian-themed art, writing, and music that stays open.

## Decision
- Source code: **MIT** (`LICENSE`).
- Original art, audio, writing, dialog, and cultural content: **CC BY-SA 4.0** (`LICENSE-ASSETS.md`).
- Fonts: OFL. Third-party assets: CC0/CC BY/CC BY-SA/OFL only, recorded in `assets/CREDITS.md`.
- Contributions are accepted under these licenses (inbound = outbound), confirmed via the PR template checkbox. A DCO sign-off (`git commit -s`) is recommended.

## Consequences
- + Commercial reuse of code is fine; derivative art stays open.
- − Name and logo are not covered. A trademark policy may come later.
