# ADR-0004: Custom lightweight i18n, EN source + ID
- Status: Accepted
- Date: 2026-09-26

## Context
We need EN and ID at launch, more locales later, tiny bundles, typed keys, and localized Ink dialog.

## Decision
Own ~2 KB runtime: namespaced flat JSON, a small ICU subset (placeholders, plural, select) on top of `Intl`, generated key types, CI parity checks, and per-locale Ink files with structure parity. See I18N.md.

## Consequences
- + Small, typed, offline-friendly, no dependency.
- − We maintain the formatter and checker. Keep features minimal.

## Alternatives considered
- i18next (+ICU plugin): heavier and more config than we need.
- Paraglide/Lingui: compile-step tooling that is less aligned with the Bun-only toolchain.
