# Contributing / Berkontribusi

🇬🇧 English below · 🇮🇩 Bahasa Indonesia di bawahnya

## 🇬🇧 How to contribute
1. **Find work:** issues labeled `good first issue`, `art-needed`, `needs-translation`, `culture-review`, or unchecked tasks in [docs/ROADMAP.md](docs/ROADMAP.md).
2. **Discuss big changes first** in an issue (new systems, dependencies, architecture). Architecture changes need an ADR ([docs/adr](docs/adr/)).
3. **Setup:** install Bun (version in `.bun-version`), then `bun install && bun run dev`.
4. **Branch:** `feat/<task-id>-<slug>` or `fix/<slug>`. **Commits:** [Conventional Commits](https://www.conventionalcommits.org/), e.g. `feat(sim): M2-02 crop growth`. Sign-off is recommended (`git commit -s`).
5. **Before opening a PR:** `bun run check` is green, strings exist in **both** `en` and `id`, and the PR template is filled in.
6. **Assets:** original work (CC BY-SA 4.0) or CC0/CC BY/CC BY-SA/OFL only, credited in `assets/CREDITS.md`. No ripped assets, and no art from AI models trained on unlicensed data that you can't verify.
7. **Culture:** read [docs/CULTURE_GUIDE.md](docs/CULTURE_GUIDE.md). Knowledge from your own region is very welcome: open a *Culture feedback* issue.

AI-assisted contributions are fine. You are responsible for reviewing, testing, and understanding everything you submit.

By contributing you agree your code is MIT-licensed and your non-code content is CC BY-SA 4.0.

## 🇮🇩 Cara berkontribusi
1. **Cari pekerjaan:** issue berlabel `good first issue`, `art-needed`, `needs-translation`, `culture-review`, atau task yang belum dicentang di [docs/ROADMAP.md](docs/ROADMAP.md).
2. **Diskusikan perubahan besar dulu** lewat issue (sistem baru, dependensi, arsitektur). Perubahan arsitektur butuh ADR.
3. **Setup:** pasang Bun (versinya ada di `.bun-version`), lalu `bun install && bun run dev`.
4. **Branch:** `feat/<task-id>-<slug>`. **Commit:** Conventional Commits.
5. **Sebelum PR:** `bun run check` hijau, teks ada di `en` **dan** `id`, dan template PR sudah diisi.
6. **Aset:** karya sendiri (CC BY-SA 4.0) atau aset berlisensi CC0/CC BY/CC BY-SA/OFL, dicatat di `assets/CREDITS.md`.
7. **Budaya:** baca CULTURE_GUIDE. Cerita, istilah, dan tradisi dari daerahmu sangat berharga: buka issue *Culture feedback*.

Kontribusi dengan bantuan AI diperbolehkan, tetapi kamu tetap bertanggung jawab me-review, menguji, dan memahami isinya.
