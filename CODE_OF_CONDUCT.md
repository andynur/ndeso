# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be welcoming and respectful, especially across cultures, regions, religions, and languages. This project is about sharing Indonesian culture with care. Harassment, discrimination, or mocking of any ethnic or religious group is not tolerated.

Report issues to the maintainers privately (GitHub profile contact, or a security advisory if sensitive). Maintainers will review and respond fairly and confidentially.
